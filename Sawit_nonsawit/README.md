## Ringkasan Proyek
Kelapa sawit merupakan salah satu komoditas penting dan terus berkembang di berbagai wilayah, salah satunya Aceh Tamiang. Perkembangan luasan perkebunan kelapa sawit dapat dilakukan oleh individu masyarakat maupun korporasi perusahaan yang bergerak di bidang tersebut. Laju perkembangan luasan perkebunan kelapa sawit perlu diidentifikasi untuk menjaga keseimbangan ekosistem lingkungan, salah satu upaya yang dapat dilakukan yaitu mengidentifikasi area perkebunan kelapa sawit menggunakan machine learning terbimbing sehingga dapat diketahui distribusi perkebunan kelapa sawit pada suatu wilayah. Prinsip identifikasi perkebunan kelapa sawit menggunakan machine learning yaitu pembuatan data training, data test, lalu menjalankan/melatihnya menggunakan metode machine learning tertentu. Pada proyek yang telah dikerjakan, pembuatan dataset machine learning menggunakan pemilihan area kelapa sawit berbasis poligon dengan jumlah data training sebanyak 800 dataset poligon perkebunan kelapa sawit. Berdasarkan analisis yeng telah dilakukan, jumlah luasan area perkebunan kelapa sawit sebesar 27643,55 ha, nilai aktual jumlah luasan perkebunan kelapa sawit dapat lebih besar dari nilai tersebut dikarenakan wilayah calon perkebunan kelapa sawit yang sudah dilakukan grid atau pengotakkan area tidak diidentifikasi sebagai perkebunan kelapa sawit. Adapun distribusi perkebunan kelapa sawit di wilayah Aceh Tamiang tersebar di berbagai wilayah pemukiman penduduk maupun wilayah yang jauh dari area pemukiman penduduk.
